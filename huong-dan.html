Hướng dẫn sử dụng PDF Editor

Ứng dụng chỉnh sửa PDF chạy ngay trên trình duyệt Chrome — sửa chữ, ảnh, bảng có sẵn, thêm chữ ký, ghép / tách trang, nhận dạng chữ trên file scan.

Cập nhật lần cuối: 20/11/2026

2. Bắt đầu: mở, lưu, in

Mở file

  • Bấm Mở (hoặc Ctrl+O) và chọn file PDF.
  • Hoặc kéo thả file PDF vào cửa sổ ứng dụng.
  • Mở ảnh JPG / PNG sẽ tạo thành file PDF (mỗi ảnh một trang).
  • Mới tạo tài liệu trắng khổ A4.

Mở lại file gần đây

  • Bấm Gần đây (cạnh nút Mở) hoặc xem danh sách File gần đây ở màn hình trống: 10 file mở / lưu gần nhất, kể cả file trên ổ mạng (G:…). Bấm tên file là mở lại.
  • Lần đầu mở lại mỗi phiên, Chrome hỏi "Cho phép xem file?" → bấm Cho phép.
  • Rê chuột lên một dòng, bấm × để bỏ khỏi danh sách; Xoá danh sách để xoá hết. Danh sách chỉ lưu trên máy này.
  • File mở bằng nút Mở, kéo thả, hoặc vừa Lưu đều được nhớ. Cần dùng Chrome hoặc Edge.

Tự lưu bản nháp

Khi đang sửa mà chưa bấm Lưu, web tự lưu bản nháp trên máy vài giây sau mỗi thay đổi. Lỡ đóng tab, trình duyệt bị tắt hay mất điện: mở lại web sẽ hiện thanh vàng "Có bản đang sửa dở chưa lưu" → bấm Khôi phục để mở lại đúng chỗ đang sửa (mỗi file một tab), rồi nhớ bấm Lưu. Bấm Bỏ nếu không cần. Lưu file xong thì bản nháp tự xoá. (Lịch sử hoàn tác không được khôi phục.)

Lưu file

  • Lưu (Ctrl+S): lần đầu chọn nơi lưu, các lần sau ghi đè lên file đó.
  • Shift + bấm Lưu (hoặc Ctrl+Shift+S): lưu thành file khác.
  • Tải xuống: tải file PDF đã sửa về thư mục Downloads.
  • In: mở bản PDF đã sửa trong tab mới để in.
MẹoTên file có dấu chấm đỏ • nghĩa là có thay đổi chưa lưu. Đóng trình duyệt khi chưa lưu sẽ được hỏi lại.

Sắp xếp bố cục (nhóm nút cạnh ô phóng to, góc phải thanh công cụ):

  • Xem 2 trang cạnh nhau (1–2, 3–4…) — hợp với bản vẽ khổ ngang nhiều trang; bấm lại để về xem 1 trang cuộn dọc. Trang tự thu vừa 2 trang trên màn hình.
  • Ẩn / hiện cột nút Trang, cột ảnh thu nhỏ, cột Thuộc tính (nút xanh = đang hiện) — ẩn bớt để vùng xem trang rộng hơn.
  • Kéo mép cột (vạch giữa các cột, con trỏ thành ↔) để đổi độ rộng; bấm đúp vào mép để ẩn cột đó. Kéo rộng cột ảnh thu nhỏ thì ảnh thu nhỏ to ra theo (dễ nhận trang bản vẽ).
  • trả bố cục về mặc định. Web nhớ cách xếp cho lần mở sau (trên máy / trình duyệt đó).

Phóng to / thu nhỏ: nút − ＋, nút ↔ (vừa chiều rộng), hoặc giữ Ctrl + lăn chuột — chỗ đang trỏ chuột đứng yên khi phóng to (phóng thẳng vào chi tiết bản vẽ). Đang ở mức vừa chiều rộng (lúc mở file hoặc bấm ↔) thì khi ẩn / kéo cột, đổi cỡ cửa sổ, trang tự vừa lại; phóng to bằng tay thì giữ nguyên mức đó.

4. Làm việc với nhiều file

  • Mỗi lần Mở hoặc kéo thả file, file mở trong tab mới — các file cũ vẫn giữ nguyên.
  • Mỗi tab có lịch sử hoàn tác và nút lưu riêng.
  • Muốn gộp file khác vào file đang mở: dùng Ghép PDF (xem mục 11).

5. Chọn đối tượng & chọn chữ

  • Bấm 1 lần vào đường kẻ / ảnh / logo có sẵn trong PDF → tách ra và chọn luôn (đường kẻ mảnh chỉ cần bấm gần).

Khi đã chọn: kéo để di chuyển, kéo góc để đổi cỡ (giữ Shift để co giãn tự do), núm tròn phía trên để xoay, phím mũi tên để nhích 1 điểm (Shift + mũi tên: 10 điểm), Delete để xoá.

6. Sửa nội dung có sẵn trong PDF

Chọn công cụ Sửa nội dung (E). Rê chuột lên trang: phần nào sửa được sẽ hiện khung xanh. Bấm vào để sửa.

Thứ tự ưu tiên khi bấmChữ → đường kẻ / hình vẽ → ảnh. Giữ Alt khi bấm để bỏ qua chữ và chọn hình / ảnh nằm bên dưới chữ.

Sửa chữ

  1. Bấm vào dòng chữ cần sửa — con trỏ nằm đúng chỗ bấm.
  2. Gõ sửa như bình thường. Bấm ra ngoài để xong.
  • Chữ cũ được xoá hẳn khỏi file (không chỉ che lên), nền và đường kẻ phía sau giữ nguyên.
  • Chữ mới giữ đúng phông, cỡ, đậm, nghiêng, màu và căn lề (trái / giữa / phải) như chữ gốc. Chữ xoay dọc (ví dụ số kích thước trên bản vẽ) cũng sửa được.
  • Chữ trong file bị kéo giãn / ép ngang (hay gặp ở khung tên bản vẽ xuất từ AutoCAD) hoặc có khoảng cách chữ riêng: chữ mới giãn đúng như vậy, dòng giữ nguyên bề ngang và vị trí như trước khi sửa.
  • Đặt khít, cố định: web so điểm ảnh của chữ gốc và chữ mới rồi dời cho mép trái, mép phải và chân chữ trùng nhau (lệch dưới 0,05 mm), cả trên màn hình lẫn file lưu ra. Ô chữ đã sửa được khoá vị trí — bấm, bôi đen, gõ thoải mái mà không bị kéo lệch.
  • Dòng có nhiều màu (vd một từ màu xanh giữa dòng) giữ đúng màu từng đoạn. Chữ được làm đậm bằng nét viền ("đậm giả") cũng giữ nguyên nét viền.
  • Dùng được cả phông Windows dạng bộ (SimSun, Cambria, Microsoft YaHei, MS Gothic…). Ký tự mà phông gốc không có (vd chữ Việt có dấu trong SimSun) tự dùng Arial cho riêng ký tự đó.
  • Phông máy chưa có: nếu là phông miễn phí trên Google Fonts (giấy phép mở, dùng thương mại được), ứng dụng tự tải về khi anh bấm sửa chữ (vài giây, có thông báo "Đã tải phông miễn phí…"). Ngoài ra đã tải sẵn khoảng 60 họ phông phổ biến có tiếng Việt (Roboto, Open Sans, Noto Sans/Serif, Montserrat, Be Vietnam Pro, Lora, Merriweather, Inter…) — có trong ô chọn phông ở cột Thuộc tính — và tự kiểm tra bản mới mỗi tuần. Phông lưu trong thư mục pdf-editor\fonts-extra, không cài vào Windows; chỉ tên phông được gửi lên Google.
  • Phông nhúng không có tên thật (vd file xuất từ AutoCAD / Illustrator ghi tên phông là "CIDFont+F1", "F1", "T1_0"): ứng dụng tự nhận phông theo hình dạng chữ — vẽ thử vài dòng chữ cùng phông trên trang bằng các phông có trên máy (Verdana, Arial, Tahoma, Times New Roman, Calibri, Segoe UI…) rồi chọn phông giống nhất, kèm đậm / nghiêng. Chữ sửa xong giữ đúng phông, cỡ và vị trí, file lưu ra trùng khít màn hình.
  • Phông thương mại (có bản quyền) không tự tải được. Nếu công ty đã mua, cài phông đó vào Windows (bấm phải file phông → Install) rồi khởi động lại máy hoặc ứng dụng, PDF Editor sẽ tự dùng.
  • Mỗi ô của bảng được sửa riêng.
Phông chữỨng dụng dùng phông đã cài trên máy chủ. Nếu PDF dùng phông máy không có, sẽ tạm dùng Arial và báo cho bạn — có thể đổi phông ở cột Thuộc tính.

Sửa ảnh, logo

  1. Bấm vào ảnh (logo, hình…) — ảnh được tách ra đúng vị trí, kích thước.
  2. Kéo để di chuyển, kéo góc để đổi cỡ, Delete để xoá.

Cột Thuộc tính có thêm: 🖼 Thay ảnh (thay bằng ảnh khác, giữ khung), Lưu ảnh (tải ảnh về máy), 🧽 Tẩy vùng trên ảnh.

Đường kẻ, bảng, khung, hình vẽ

  • Bấm gần 1 đường kẻ → chọn đúng đường đó. Đổi màu, độ dày ở cột Thuộc tính hoặc xoá.
  • Kéo khung quanh cả bảng (bằng Sửa nội dung hoặc Chọn đối tượng) → tách mọi đường kẻ, hình, ảnh trong khung để di chuyển / xoá / copy cả cụm.
  • Hình được tách ra mà trong file gốc nằm dưới chữ (vd nền màu của bảng) sẽ tự giữ ở lớp dưới nội dung PDF, nên bấm nhầm vào nền cũng không làm mất chữ. Muốn đưa lên trên, dùng nút Lên trên cùng ở cột Thuộc tính.

Tẩy ảnh — xoá một phần ảnh (ví dụ hình mờ trong ảnh nền)

Nhiều file (hoá đơn điện tử…) có ảnh nền phủ cả trang chứa viền hoa văn và hình mờ. Bấm vào ảnh nền, ứng dụng tự chuyển sang Tẩy ảnh:

  1. Kéo khung lên phần muốn xoá (ví dụ hình mờ ở giữa trang).
  2. Phần đó biến mất; viền, chữ, bảng vẫn giữ nguyên. Kéo nhiều lần được.
  3. Nhấn Esc để xong; Ctrl+Z để hoàn tác.

7. File scan: nhận dạng chữ (OCR)

File scan / chụp là ảnh, chữ nằm trong ảnh nên phải nhận dạng trước khi sửa.

  1. Bấm Nhận dạng chữ (OCR) ở cột trái: web quét tất cả trang scan của file 1 lần (trang đã có chữ thật hoặc đã nhận dạng thì bỏ qua). Hoặc bấm vào chữ bằng Sửa nội dung, ứng dụng sẽ hỏi có nhận dạng trang đó không.
  2. Chờ vài giây / trang (thanh chờ ghi đang quét trang nào). Lần đầu cần Internet để tải dữ liệu tiếng Việt (~10 MB).
  3. Quét xong, web ở chế độ Chọn đối tượng: bấm 1 lần vào dòng chữ là sửa được ngay (dùng Sửa nội dung cũng được).

Chữ cũ được che bằng đúng màu giấy. Chữ mới giữ nguyên kiểu chữ của bản scan:

  • Phông chữ: tự nhận ra phông gần giống nhất (Times New Roman, Arial, Calibri, Cambria, Tahoma, Verdana, Segoe UI, Courier New) bằng cách so hình dạng từng từ với bản scan.
  • Cỡ chữ, đậm / thường, nghiêng, màu mực và vị trí (cùng chân chữ). Chữ sáng trên nền màu (vd số trắng trong ô xanh) cũng giữ đúng màu chữ và màu nền.
  • Độ đậm: phân biệt cả các mức Light / thường / Semibold (nửa đậm) / đậm / Black của Segoe UI, Calibri, Arial. Đậm hay thường được so với các dòng khác trên cùng trang (lần sửa đầu tiên trên mỗi trang mất thêm 1–2 giây để đo), nên bản photocopy nét chữ dày vẫn ra đúng chữ thường; chỉ tiêu đề dày hẳn hơn mới thành chữ đậm.
  • Gạch chân: dòng gốc có gạch chân (vd tiêu đề "ĐIỀU 3: …") thì chữ mới cũng có gạch chân.
  • Khoảng cách: giãn chữ cho dòng mới dài bằng dòng cũ; chỗ cách 2 dấu cách cũng được giữ.
  • Độ nhoè: chữ mới được làm nhoè nhẹ giống chữ trong ảnh scan (khi đang gõ thì hiện nét rõ). Khi lưu PDF, dòng chữ đó được lưu thành ảnh nhỏ cùng độ nét với bản scan.
  • Đồng đều trong bảng: các ô số ngắn trên cùng trang tự lấy theo phông, độ đậm, cỡ chữ của các ô đã sửa trước đó.

Gạch chân, đường kẻ bảng và chữ in sẵn màu khác (vd chữ xanh của biểu mẫu) được bỏ qua khi đo nên không làm sai kiểu chữ. Dòng rất ngắn (1–2 từ) khó đoán thì lấy theo phông các dòng khác trên trang. Nếu vẫn chưa đúng ý, chọn ô chữ rồi đổi phông / cỡ ở bảng Thuộc tính bên phải.

Luôn kiểm tra lại chữOCR có thể đọc sai, nhất là dấu tiếng Việt (ví dụ "Nguyễn" thành "Nguyên") và chỗ bị con dấu / chữ ký đè (vd "CÔNG TY … GỖ" đọc thành "CONG TY … GO") — đọc lại từng dòng khi sửa. Sửa xong chữ đọc sai, web tự đo lại phông / đậm / nghiêng / cỡ theo chữ đúng trên đúng chỗ đó của bản scan (có thông báo nếu kiểu chữ thay đổi). Chữ đậm (tiêu đề) được so với chữ thường của cả trang và ưu tiên cùng họ phông với chữ thường (vd Times đậm). Chữ viết tay, con dấu, chữ ký không nhận dạng được — dùng Tẩy ảnh hoặc Xoá trắng.

Sửa cả đoạn nhiều dòng

Khi dòng vừa bấm thuộc một đoạn nhiều dòng, bảng nhỏ có nút ¶ Sửa cả đoạn (N dòng). Bấm vào: cả đoạn thành 1 ô chữ — gõ thêm / bớt thì chữ tự xuống dòng, căn đều 2 bên như bản gốc (dòng cuối để thường), ngắt dòng ban đầu đúng như bản scan; kéo cạnh khung để đổi độ rộng. Web tự nhận đoạn: các dòng sát nhau, cùng lề trái, dòng trên chạm lề phải; dòng có gạch đầu dòng (–, +, •) là bắt đầu đoạn mới.

10. Sao chép, dán (cùng trang, trang khác, file khác)

Quét chọn rồi dán vào vị trí khác

  1. Chọn công cụ Chọn đối tượng V, kéo khung quanh phần muốn sao chép (vài ô bảng, khung tên, logo, đoạn chữ, kể cả trên file scan).
  2. Nếu trong khung có chữ / ảnh gốc của PDF, hiện khung xanh nét đứt có 2 nút Sao chép và Xoá ở phía trên. Chỉnh khung: kéo 8 nút trắng ở góc / cạnh để khung vừa khít, khỏi phải quét lại. (Ở công cụ Chọn đối tượng, rê chuột không hiện khung xanh nữa.) Nếu chỉ có đối tượng đã thêm / đường kẻ thì chúng được chọn như thường.
  3. Bấm nút Sao chép (hoặc Ctrl+C).
  4. Trỏ chuột vào chỗ muốn dán (cùng trang, trang khác hoặc tab file khác) rồi bấm Ctrl+V — phần dán nằm với góc trên-trái tại con trỏ chuột. Sau đó kéo để chỉnh lại vị trí nếu cần.

Chuột không nằm trên trang nào khi bấm Ctrl+V: dán sang file khác thì giữ đúng vị trí như ở file nguồn, dán cùng trang thì lệch xuống một chút. Esc bỏ khung vùng chọn.

Dời cả vùng sang chỗ khác

Khi đang có khung xanh nét đứt: bấm giữ chuột bên trong khung rồi kéo tới chỗ mới (con trỏ hình mũi tên 4 chiều). Lúc kéo, khung mang theo hình của vùng, chỗ cũ hiện trắng mờ viền đỏ. Thả chuột: mọi thứ trong vùng (chữ, nét vẽ, ảnh, đối tượng đã thêm) chuyển sang chỗ mới, chỗ cũ trống hẳn; khi lưu, phần nội dung gốc vẫn giữ nét vector sắc nét. Khung chọn đi theo vùng nên kéo tiếp được để chỉnh; Ctrl+Z một lần là trả lại như cũ. (Chỉ dời trong cùng trang — sang trang / file khác thì dùng Sao chép + Ctrl+V rồi Xoá chỗ cũ.)

Xoá vùng đã quét chọn

Xem trước: rê chuột vào nút Xoá trên khung — vùng sắp mất hiện trắng mờ, viền đỏ, để thấy trước có lấn sang chữ bên cạnh không (chưa xoá gì). Bấm nút Xoá, hoặc Delete / Backspace: mọi thứ trong khung bị xoá hẳn khỏi file (không phủ ô trắng): chữ gốc, nét vẽ / đường kẻ nằm trong khung, phần ảnh gốc trong khung (vd chữ trên bản scan), đối tượng đã thêm. Nét vẽ / ảnh / chữ vắt ngang qua khung bị cắt đúng theo mép khung — trong khung sạch hẳn, phần bên ngoài giữ nguyên. Bấm Delete ngay khi vừa quét cũng được — web xoá khi quét xong. Muốn lấy lại thì bấm Ctrl+Z (một lần là đủ). Lưu ý kéo khung vừa khít phần muốn xoá, tránh lấn sang dòng bên cạnh.

Ô trang ghi "A3↔B4" = trang 3 bản A ứng với trang 4 bản B; ô A2 = trang bị bỏ (chỉ có ở bản A); ô xanh B3 = trang mới thêm ở bản B. Tìm chữ trong file (Ctrl+F)

Bấm Ctrl+F: thanh tìm hiện ở góc trên vùng xem trang. Gõ chữ cần tìm — mọi chỗ trùng trên các trang được tô vàng, chỗ đang xem tô cam và tự cuộn tới; ô đếm ghi "3 / 12". Enter / F3 tới chỗ sau, Shift+Enter về chỗ trước, Esc đóng.

  • Tìm được trong chữ gốc của PDF, chữ trên trang scan đã OCR, và chữ đã thêm / đã sửa.
  • Aa: phân biệt chữ hoa / thường. a≈á: bỏ qua dấu tiếng Việt — gõ "hop dong" vẫn ra "hợp đồng", "nghia son" ra "NGHĨA SƠN". Web nhớ lựa chọn cho lần sau.
  • Đang bôi đen chữ (công cụ Chọn chữ) rồi bấm Ctrl+F thì chữ đó được điền sẵn vào ô tìm.
  • Thay…: mở hộp Tìm & thay với chữ đang tìm để thay hàng loạt (giữ phông / cỡ / màu).

14. Lưu ý & giới hạn

Chứng từ có chữ ký số, con dấuHoá đơn điện tử, biên bản đã ký: sửa bất kỳ chi tiết nào thì chữ ký số mất hiệu lực và file không còn là bản gốc. Khi dùng cho kế toán, nộp cơ quan hoặc gửi đối tác như chứng từ thật, hãy dùng file gốc.
  • Ứng dụng cần Internet để tải thư viện khi mở lần đầu và để tải dữ liệu OCR.
  • File có phông nhúng bị hỏng (vd file song ngữ dịch bằng Kingsoft PDF, chữ hiện thành ký tự rác): khi mở, ứng dụng tự thay phông hỏng bằng Arial theo đúng mã chữ trong file và báo "đã tự thay bằng Arial". File lưu ra cũng dùng phông đã sửa nên mở bằng chương trình khác vẫn đúng. Kiểu chữ có thể hơi khác bản gốc.
  • Chữ trong file scan phải nhận dạng (OCR) trước khi sửa; kết quả OCR cần kiểm tra lại.
  • Nền hoa văn lặp lại (pattern), dải màu chuyển sắc chưa tách / sửa riêng được.
  • File có mật khẩu: nhập mật khẩu khi mở; một số file mã hoá có thể lưu không đúng.
  • Ứng dụng không lưu file trên máy chủ — hãy bấm Lưu / Tải xuống trước khi đóng.

15. Hỏi đáp nhanh

Bấm vào chữ mà không sửa được?

Kiểm tra đang dùng công cụ Sửa nội dung (hoặc bấm đúp bằng Chọn đối tượng). Nếu rê chuột không hiện khung xanh: chữ đó là nét vẽ hoặc nằm trong ảnh scan → dùng OCR (mục 7) hoặc Xoá trắng + T Thêm chữ.

Đưa logo xuống dưới thì bị mất?

Dùng ↓ Xuống 1 lớp hoặc ⤓ Dưới cùng — logo nằm dưới chữ nhưng vẫn trên ảnh nền. Nếu vẫn bị che, có thể trang có mảng tô trắng phủ kín: bấm ↑ Lên 1 lớp.

Lỡ tay xoá / sửa sai?

Ctrl+Z (hoàn tác), Ctrl+Y (làm lại).

Ứng dụng không hiện bản mới nhất?

Nhấn Ctrl+F5 để tải lại trang.

In hướng dẫn này?

Bấm In / Lưu PDF ở góc trên, chọn máy in hoặc "Lưu dưới dạng PDF".
